# 🚀 SCHNELLSTART - Embroidery Converter

## 3 Schritte zur funktionierenden App

### 1️⃣ DMG öffnen
- Gehen Sie zu **Downloads**
- Doppelklick auf `Embroidery Converter-1.0.0-arm64.dmg`
- Installationsfenster öffnet sich

### 2️⃣ App kopieren
- **Ziehen Sie das App-Symbol in den Applications-Ordner** (Drag & Drop)
- Warten Sie bis fertig

### 3️⃣ Cleanup durchführen (WICHTIG!)
Öffnen Sie das **Terminal** und geben Sie ein:

```bash
/Applications/Embroidery\ Converter.app/Contents/Resources/pybin/convert --help
```

Dieser Befehl entfernt die macOS-Sicherheitsattribute. Das ist ein einmaliger Vorgang!

---

## ✅ App starten

Nach dem Cleanup können Sie die App normal starten:
- **Im Finder**: Applications → Embroidery Converter doppelklicken
- **Im Terminal**: `open /Applications/Embroidery\ Converter.app`
- **Mit Spotlight**: `⌘ + Space` → "Embroidery Converter" eingeben

---

## ⚠️ Falls immer noch Warnung kommt?

Führen Sie den Befehl nochmal aus:

```bash
/Applications/Embroidery\ Converter.app/Contents/Resources/pybin/convert --help
```
