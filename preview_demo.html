🎨 Input Preview Gallery

Visual demonstration of the embroidery file preview feature

📋 What is the Input Preview Gallery?

When you add embroidery files to the converter, each file gets a thumbnail preview showing the actual stitch pattern in its thread colors. This helps you:

  • Visually verify the design before conversion
  • See thread colors exactly as they appear in the file
  • Identify files quickly when working with multiple designs
  • Check quality - preview is rendered from actual stitch coordinates

⚙️ How it works

Backend: The Python convert.py script includes a _preview_polylines() function that extracts stitch coordinates and thread colors from each file. It returns JSON with:

  • {left, top, width, height} - bounding box in 1/10mm units
  • lines: [{hex, pts: [[x,y], ...]}] - polylines per thread color
  • Smart decimation when stitch count > 4000 to keep payload small

Frontend: The renderer.js draws these polylines on a 54×54px canvas with 6px padding, auto-scaling to fit and preserving thread colors.
