## 📖 Installation Instructions

### macOS
1. **Download** the `.dmg` file for your Mac type
2. **Double-click** the `.dmg` to open it
3. **Drag** "Embroidery Converter" to Applications folder
4. **Open** Applications folder → Launch "Embroidery Converter"
5. If prompted: Right-click → Open → Open (to bypass security warning)

✅ Done! The app is installed.

### Windows
1. **Download** the `.exe` installer
2. **Double-click** to run the installer
3. Follow the installation wizard:
   - Choose installation location (default: `C:\Program Files`)
   - Select Start Menu folder
   - Choose desktop shortcut (recommended)
4. Click **Install** and wait for completion
5. Click **Finish** to launch the app

✅ Done! The app is installed and ready to use.

## 🔍 Finding the Right Version

### How to know your processor type:

**macOS:**
- Click Apple menu → About This Mac
- See "Chip" = Apple Silicon (arm64) ✓
- See "Processor" = Intel (x64) ✓

**Windows:**
- Right-click Start → System
- Look for "Processor" line
- If it says "ARM64" or contains "Snapdragon" = ARM (rare)
- Otherwise = x64 (standard) ✓

## 🆘 Download Issues?

### Download stalls or fails?
- Check your internet connection
- Try downloading again (some browsers have resume capability)
- Try a different browser

### Got wrong file for your OS?
- Check file extension:
  - macOS should end in `.dmg`
  - Windows should end in `.exe`
- Download the correct one and try again

### File seems corrupted?
- Delete the downloaded file
- Re-download from Releases page
- Verify file size matches (shown on Releases page)

### Can't find your processor version?
- See "Finding the Right Version" section above
- When in doubt, try the most common version first:
  - **macOS:** arm64 (newer Macs)
  - **Windows:** x64 (standard Windows)
